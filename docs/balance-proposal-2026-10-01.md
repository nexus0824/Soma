## 1. 시뮬레이션 전제

- 타수 = 평균 공격력 / (적 방어 경감 후 피해). 콤보 배율, 치명타, 스킬은 제외했다.
- 접사는 풀에서 균등 추출한 기댓값을 썼다. 플레이어 레벨은 난이도 레벨과 같거나 약간 높다고 가정했다.
- 정예는 오우거 기반(HP×1.8, 공격×1.3), 보스는 guardian 이다.
- 장비 단계 정의

| 단계 | 구성 |
|---|---|
| 맨몸 | 장비 없음 |
| 무기만 | 희귀 무기 1개 |
| 표준 | 희귀 무기 + 나머지 9칸 마법 |
| 희귀 풀 | 10칸 전부 희귀 |
| 유니크 풀 | 10칸 전부 유니크 |

- 현재 수치 검증: 검사 Lv1/Lv5 의 고블린 3~4타, 오우거 10~16타는 요청서의 측정값과 일치한다. 요청서의 "Lv10 유니크 풀 경감 63%" 는 시뮬레이션에서 65% 로 근접하다.

## 2. 문제 진단 (현재 수치)

| 지표 | Lv1 | Lv5 | Lv10 | Lv20 | Lv30 | 판단 |
|---|---|---|---|---|---|---|
| 표준 장비 경감률 | 31% | 43% | 52% | 64% | 72% | 상승 중 |
| 유니크 풀 경감률 | 43% | 56% | 65% | 75% | 81% | **과함** |
| 유니크 풀 보스 처치 타수 | 16 | 18 | 18 | 18 | 18 | 6~7초 컷, 항상 같음 |
| 유니크 풀 보스 1타 피해(최대HP%) | 5.8 | 4.2 | 3.2 | 2.1 | 1.6 | 사실상 무적 |
| 표준 장비 고블린 1타 피해(최대HP%) | 3.5 | 2.9 | 2.3 | 1.7 | 1.3 | 위협 없음 |

결론은 두 가지다.

1. **유니크 풀 63% 경감은 과하다.** 문제는 숫자 자체보다 `defenseK` 가 고정이라 경감률이 레벨과 함께 85%까지 오르는 구조다. 이 구조에서는 장비를 갖춘 순간 전투 긴장이 사라진다.
2. **장비가 적 성장보다 빠르게 큰다.** 유니크 풀 보스 처치 타수가 구간에 상관없이 18타에 고정되므로 보스전이 긴장 없는 소모전이 된다.

### 3-8. "장비 없이 레벨만 올리면 어디서 막혀야 하는가"

### 4-5. 점검할 코드 리스크

- 정예 보상은 `remainingInRoom(room) <= 1` 일 때만 나온다. 소환체에 `room` 이 없으면 소환 몹이 남아 있어도 보상이 사라지거나 중복될 수 있다. 소환체를 방에 귀속시키는지 확인이 필요하다.
- 동료 장비 킷도 `scene.level` 기준으로 생성하므로, 3-1 변경이 동료 스탯에도 그대로 반영된다.

### 4-6. 골드 경제

| 위치 | 잡몹 골드 드롭/층(예상) | 판매가 일반/마법/희귀/유니크 |
|---|---|---|
| 폐허 1층 (L1) | 약 34 | 7 / 18 / 42 / 105 |
| 폐허 5층 (L5) | 약 124 | 19 / 48 / 114 / 285 |
| 납골 1층 (L9) | 약 106 | 31 / 78 / 186 / 465 |
| 용광로 1층 (L19) | 약 210 | 61 / 153 / 366 / 915 |
| 심층 10층 (L39) | 약 851 | 121 / 303 / 726 / 1,815 |

층당 수입은 골드 드롭에 아이템 판매 3~4개를 더해 폐허 5층 약 300, 용광로 1층 약 700 수준이다. 쓸 곳이 없다는 문제는 맞다. 소모처는 **판매가에 비례하는 방식**으로 설계하면 레벨이 올라도 비율이 자동 유지된다.

| 소모처 (신설 제안) | 가격식 | 목표 비중 |
|---|---|---|
| 접사 1개 재굴림 | 대상 아이템 판매가 × 2.0 | 같은 구간 층당 수입의 0.5~0.8배 |
| 강화 +1~+5 (기본치 단계당 +6%) | 같은 레벨 일반 판매가 × 4 × 단계² | 구간 클리어 수입의 30~40% |
| 사망 시 제자리 부활 (1회) | 현재 골드의 15% | 사망 패널티와 상쇄 |
| 허브 회복약(소모품) | 판매가 일반 × 1~2 | 보스전 전 준비용 |
| 가방 확장 (20→30→40) | 2,000 / 6,000 | 장기 목표 |

골드는 이 소모처가 생길 때까지 "쓸 곳 없는 숫자" 로 남는다. 그 전까지는 판매 수입 자체를 줄이는 방법도 있지만, 경제 구조를 만든 뒤에 조정하는 편이 낫다.

모든 타수는 콤보 1~3타 구분 없이 평균 1회 타격 기준이다. 시뮬레이션 모델과 실측은 ±1~2타 오차를 허용한다.

## 6. 위험과 결정이 필요한 사항

| 항목 | 내용 |
|---|---|
| **구세이브 장비** | 이미 굴려진 아이템은 `base.value` 가 저장되어 있어 새 아이템보다 강하다. SAVE_VERSION 을 올려 인벤토리·장비를 초기화할지, 그대로 둘지 사용자 결정이 필요하다. 이전 세션에서 직업 기본치가 이미 크게 바뀌었으므로 초기화를 권한다 |
| **K 방식 vs 상한 방식** | K 방식은 모든 레벨에서 평평한 경감률을 주지만 구현이 한 곳 늘고 튜닝 변수가 하나 더 생긴다. 상한 방식은 단순하지만 상한 도달 후 방어 접사가 무의미해진다. K 방식을 권한다 |
| **법사 단일 대상** | 간이 모델 한계로 확신이 낮다. 실전 측정 후 확정한다 |
| **유니크 존재감** | 유니크 비율을 낮추면 희소해지는 대신 얻었을 때 체감이 커져야 한다. 장비 획득 연출은 별도 작업이므로, 연출이 약하면 유니크 비율을 소폭 올릴 수 있다 |
| **간이 모델의 한계** | 치명타, 콤보 배율, 스킬 데미지, 동료 지원은 계산에서 제외했다. 실제 처치 속도는 표보다 빠르고, 따라서 보스 HP 1500 은 하한이다 |
